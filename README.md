# IT Navigator — канал обновлений

Публичные артефакты для desktop-клиента. Исходники: приватный репозиторий.

Клиент скачивает `releases/latest/download/`:

- `content-catalog.json`
- `python-beginner.navpack` / `python-advanced.navpack`
- `latest.json` + `IT-Navigator-Setup.exe` (+ `.sig`)

Публикация из исходников: `npm run publish:content` или `npm run publish:shell`.
